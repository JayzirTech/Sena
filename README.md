# SENA - Proyectos y Actividades

Repositorio centralizado para el seguimiento y almacenamiento de proyectos, talleres y evidencias formativas desarrolladas en el **SENA** (Servicio Nacional de Aprendizaje).

## 📁 Contenido del Repositorio

- **[`ejercicio_pausa_activa/`](./ejercicio_pausa_activa/)**: Sistema y generación de documentación técnica para el proceso de compra en pausas activas.
- **[`ejercicio_prestamo_portatiles/`](./ejercicio_prestamo_portatiles/)**: Sistema de control y gestión de préstamos de computadores portátiles.
- **[`TransCaribeCol/`](./TransCaribeCol/)**: Actividad 3.4 - Módulo de nómina y honorarios para personal administrativo y operativo.
- **[`sistema_calificaciones/`](./sistema_calificaciones/)**: Reto principal - Sistema de registro y procesamiento de calificaciones, promedios, estados y estadísticas grupales.
